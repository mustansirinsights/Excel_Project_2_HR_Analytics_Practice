# Excel Project 2 – HR Analytics Practice

## Project Overview

This project is an HR Analytics project created using Microsoft Excel to analyze employee data and generate meaningful workforce insights.

The project focuses on employee demographics, salary analysis, experience, satisfaction, workforce metrics, and key HR performance indicators.

## Key Features

- Employee data analysis
- HR KPI analysis
- Salary and compensation analysis
- Employee experience analysis
- Employee satisfaction analysis
- Workforce insights
- Data visualization and dashboards

## Tools & Techniques Used

- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Pivot Charts
- KPIs
- Data Visualization
- Dashboard Analysis
